## Отклонённые кандидаты (показывается «нет перевода») — 11

- пол: «ярты» — «ярты» = половина (омоним «пол-»); пол (поверхность) — идән, нужен источник
- форма: «рәвеш» — рәвеш = форма (вид); для «военная форма» нужно иное слово
- ручка: «сап» — сап = рукоятка; для шариковой ручки нужен источник (каләм?)
- скат: «сөзәклек» — сөзәклек = склон; рыба-скат — другое слово
- колонка: «багана» — багана = столб/колонна; колонка (динамик) — другое
- краски: «краски» — статья ттвики о деревне Краски
- факел: «факел» — статья ттвики о посёлке Факел
- платье: «кием» — кием = одежда вообще
- бюст: «гәүдә» — гәүдә = тело/туловище
- губная гармошка: «гармун» — гармун = гармонь
- кисть: «чук» — чук = кисть (гроздь/бахрома), не кисть-инструмент
